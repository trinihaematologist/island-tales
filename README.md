# Island Tales

A responsive, child-friendly Caribbean folklore website prototype.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any simple static web server.

## Included
- Responsive single-page site
- Six illustrated folklore character cards
- Child-friendly story modals
- Interactive Caribbean story map
- Story prompt generator
- Three-question personality quiz
- Research/source section
- Accessibility-conscious navigation and reduced-motion support

## Content approach
The site treats folklore as living oral tradition. Retellings are intentionally child-friendly and state where traditions vary. Core research was drawn from NALIS (Trinidad and Tobago) and UNESCO material on oral tradition and Anansi.
